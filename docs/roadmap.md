# AI Topic Evaluator - Development Roadmap

## Project Vision

Build an AI-powered platform that helps users improve their speaking and writing skills by assigning randomized subtopics and providing personalized AI evaluation.

---

## User Flow

1. User visits the website.
2. User chooses:
   - Speaking or Writing mode
   - Main topic
   - Preparation time
   - Response time
   - Evaluation strictness
3. System randomly selects a subtopic.
4. System provides trusted references/citations.
5. Preparation timer starts.
6. User submits a spoken or written response.
7. AI evaluates the response.
8. User receives:
   - Overall score
   - Criterion-wise scores
   - Strengths
   - Weaknesses
   - Personalized suggestions
   - Improved sample response
9. Session is saved in history.
