# Product Requirements Document (PRD)

## Project Name

AI Topic Evaluator

---

# Objective

Build an AI-powered web application that helps users practice speaking and writing on randomly assigned subtopics and receive structured AI-generated feedback.

---

# Target Users

- Students
- Placement aspirants
- Interview candidates
- Public speaking learners
- Content writers

---

# User Journey

1. User opens the application.
2. User selects:
   - Speaking / Writing
   - Main Topic
   - Preparation Time
   - Response Time
   - Evaluation Strictness
3. System randomly assigns a subtopic.
4. System displays trusted references.
5. Preparation timer starts.
6. User submits response.
7. AI evaluates response.
8. User views detailed report.
9. Session is saved for future review.

---

# Functional Requirements

## Topic Engine

- Predefined topics
- Multiple subtopics under each topic
- Random selection
- Avoid immediate repetition

---

## Reference Engine

Each subtopic contains:

- Articles
- Research papers
- Government reports
- News references

---

## Timer Engine

Preparation Timer

- 2
- 5
- 10
- 15 minutes

Response Timer

Writing

- 2–10 minutes

Speaking

- 1–10 minutes

---

## Evaluation

Modes

- Lenient
- Moderate
- Strict

Criteria

- Grammar
- Vocabulary
- Sentence Formation
- Structure
- Coherence
- Terminology
- Critical Thinking
- Fluency (Speaking)
- Confidence (Speaking)

---

## Dashboard

- Session History
- Average Score
- Best Score
- Weakest Skills
- Improvement Graph
